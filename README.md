# Fatos ⭐

Jogo para crianças praticarem os fatos básicos de **adição, subtração, multiplicação e divisão**.

## Como jogar

1. Escolha uma ou mais operações no menu (+, −, ×, ÷). Elas podem ser combinadas.
2. Toque em **Começar** (o botão vira **Reiniciar**).
3. Aparece um fato como `4 + 3 =`. Toque/clique na tela para ver a resposta (`4 + 3 = 7`) e toque de novo para o próximo.
4. Use **Pausar** para parar o cronômetro. O jogo também pausa sozinho ao sair da aba.

Teclado: espaço, Enter ou → avançam; **P** pausa/continua.

## Fatos incluídos

- **Adição** e **multiplicação**: todas as combinações de 0 a 10 (121 fatos cada).
- **Subtração**: todas as inversas da adição (121 fatos).
- **Divisão**: todas as inversas da multiplicação, sem divisão por zero (110 fatos).

Os fatos são embaralhados e cada um aparece uma vez por rodada.

## Rodando

Site estático, sem dependências: abra `index.html` no navegador ou publique a pasta no GitHub Pages.
